Second proofreading pass (October 22, 2026, not yet committed)
--------------------------------------------------------------

All 13 chapters were read again.  About 65 further slips were fixed.  The
following fixes change the content and should be reviewed:
- recurrence-equations.tex: in the degenerate case (4*b + a^2 = 0), a + b = 1
  forces (a-2)^2 = 0, i.e. a = 2 and b = -1.  The sub-case "a + b = 1 and
  a != 2" was therefore empty, and the summary used gamma = c/(2-a) = c/0.
  The case is now merged into the case a = 2, b = -1 (main text and summary).
- graph.tex: a cycle was defined as any closed path of length >= 2, so [x,y,x]
  was a cycle and no graph with an edge could be a tree.  Now: n >= 3 and
  x_0, ..., x_{n-1} pairwise different.  In the proof of the tree proposition
  the edges are split as E \ {{x,y}}, and the second case reads
  "C empty and either #E_A < a-1 or #E_B < b-1".
- graph.tex: Dijkstra proof "for all i = 0, ..., n" (was 1); a path
  [x_0,...,x_n] connects x_0 with x_n (was x_1); topological sorting: the
  solution must also satisfy len(S) = #T, indices are 0..len(S)-1.
- complexity.tex: "f in Theta(g) if and only if the limit exists" was wrong
  (the limit need not exist); now "if".  The recurrences for power hold for
  l > 0 only (for l = 0 they contradicted the initial values).  A comparison
  sort needs "about" n*log2(n) comparisons, not "at least".
- sorting.tex: counting sort was announced as the last section of the chapter;
  dual pivot quicksort: y := L[1] (as in the code, was L[-1]); average case of
  quicksort uses H_n = ln(n) + O(1); quicksort needs "1.39 times as many"
  comparisons as merge sort.
- prioqueue.tex: after the swap in heapsort the heap is A[0:n], not A[0:n-1].
- monte-carlo.tex: wrong line numbers (x, y are computed in lines 4 and 5,
  r in line 6).
- correctness.tex: power was analysed in the complexity chapter, not in "the
  last chapter".
- introduction.tex: the overview now lists the correctness chapter (it had
  been commented out), lists Bellman-Ford instead of breadth first search
  (which is not in the book), and describes the Monte Carlo chapter as it is
  (pi, Monty Hall, random permutations; the poker example is not in the book).
